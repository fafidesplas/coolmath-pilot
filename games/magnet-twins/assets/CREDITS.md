# Magnet Twins: art and audio credits

Only the files the game uses are kept, in `assets/art/<style>/`, with each pack's own license
file next to them. Licenses were checked on each pack's page on 2026-11-18. Kenney sounds were
converted from OGG to mono MP3 so Safari can play them; images are the original files.

Switch styles with `?art=<id>`, the pill at the bottom left, or the V key.

## classic (default)
- Everything drawn in code, system font, synthesized WebAudio sounds. Original work, no third-party assets.
