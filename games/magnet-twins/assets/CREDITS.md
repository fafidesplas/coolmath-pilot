# Magnet Twins: art and audio credits

Switch styles with `?art=<id>`, the pill at the bottom left, or the V key. Each style keeps only
the files the game uses, in `assets/art/<id>/`, next to each pack's license file. Licenses were
checked on each pack's own page on 2026-11-18. Robot frames, tiles and objects were cut out of the
packs and packed into small sheets (`plus.png`, `minus.png`, `tiles.png`, `objects.png`), and
scaled where noted; the pixel art is never rescaled. Kenney sounds were converted from OGG to mono
MP3 so Safari can play them.

What stays drawn in code in every style: the magnetic fields and aim previews, the plus/minus
badges on the robots, the rails of the hanging platform, the exit lamps, the HUD, buttons and
panels. Plates and the checkpoint flag are drawn in code where the pack has no match (noted below).

## classic (default)
- Everything drawn in code, system font, synthesized WebAudio sounds. Original work, no third-party assets.
