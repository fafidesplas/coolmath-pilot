# Echo Steps: art credits

Art styles switch live with `?art=<id>`, the pill at the bottom of the screen, or the **V** key. Every downloaded file is in `assets/art/<id>/`, next to its license. All of them can be used commercially without asking: CC0 (public domain) art and SIL Open Font License fonts. Sound effects are synthesized in code (`src/audio.js`), so no audio files are used.

## classic: Night Neon (default)
- Everything is drawn in code (shapes, glows, system font). No downloaded files.
- License: the game's own art.

## pixel: Pixel Meadow
- **Pixel Platformer** (1.2) by Kenney (www.kenney.nl). License: **CC0 1.0** (public domain). Pack page: https://kenney.nl/assets/pixel-platformer
  - Files: `tilemap_packed.png` (tiles, plates, gates, door, flag, plants), `tilemap-characters_packed.png` (player and echoes), `tilemap-backgrounds_packed.png` (sky). License text: `art/pixel/License-Kenney.txt`.
- **Silkscreen** (Bold) by Jason Kottke. License: **SIL Open Font License 1.1**. Font page: https://fonts.google.com/specimen/Silkscreen (file taken from https://github.com/google/fonts/tree/main/ofl/silkscreen)
  - File: `Silkscreen-Bold.ttf`. License text: `art/pixel/OFL-Silkscreen.txt`.
