# Echo Steps: art credits

Art styles switch live with `?art=<id>`, the pill at the bottom of the screen, or the **V** key. Every downloaded file is in `assets/art/<id>/`, next to its license. All of them can be used commercially: CC0 (public domain) art and SIL Open Font License fonts. Sound effects are synthesized in code (`src/audio.js`), so no audio files are used. Previews of each style (room 9, High Plate) are in `assets/art/previews/`.

## classic: Night Neon (default)
- Everything is drawn in code (shapes, glows, system font). No downloaded files.
- License: the game's own art.
